# Cổng Dữ liệu Đất đai Phía Nam

Trang chủ giao diện cho Trung tâm Dữ liệu và Thông tin đất đai (Chi nhánh văn phòng Phía Nam),
được thiết kế theo Material Design và phù hợp cơ quan nhà nước.

## Mục tiêu
- Tái hiện cấu trúc trang bandovn.vn theo phong cách hiện đại.
- Nhấn mạnh dịch vụ công trực tuyến, khai thác dữ liệu, và tra cứu hồ sơ.
- Đồng bộ với blueprint kiến trúc hệ thống dữ liệu đất đai.

## Tech stack (UI)
- React 18 + Vite
- Material UI (Material Design)
- TypeScript

## Tài liệu
- `docs/PROJECT_BLUEPRINT.md` (kiến trúc hệ thống, ERD, API, routes)

## Chạy dự án
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
